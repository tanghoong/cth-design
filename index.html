Design system

One system, every tanghoong property.

Extracted from cv.tanghoong.com and normalised into a token set, a component library and an agent prompt. Every new sub-domain, page or repo starts here so nothing drifts.

Start with foundations Copy the agent prompt llms.txt

Building with an agent? Point it at /llms.txt — the whole system as one plain-text spec. These pages are for humans.

System fonts, no webfont request. Light and dark from one light-dark() token set. Every control clears a 44 px touch target. Zero build step — the CSS files are the artefact.

Four rules the whole system rests on

Break these and a page stops looking like it belongs.

  1. Every value comes from a token

    No literal hex, px, radius or duration outside tokens.css. If a value you need does not exist, add it to the token file — do not inline it.

  2. Four surfaces, three inks, one accent

    Page, sunken, elevated, glass. Text, text-2, text-3. One accent, used sparingly enough that it still means something.

  3. Spacing belongs to the container

    Sections own vertical rhythm; grids own gaps. Components should not carry outer margins.

  4. Native elements first

    <dialog>, <details>, real <label>s. You inherit focus management, keyboard handling and assistive-tech support for free.

Using it in a new project

Copy assets/css/ into the new repo and link the files in this order. Order matters: tokens must resolve before anything references them, and utilities must come last so they can win.

Link order
<link rel="stylesheet" href="/assets/css/tokens.css">
<link rel="stylesheet" href="/assets/css/base.css">
<link rel="stylesheet" href="/assets/css/layout.css">
<link rel="stylesheet" href="/assets/css/components.css">
<link rel="stylesheet" href="/assets/css/forms.css">
<link rel="stylesheet" href="/assets/css/overlays.css">
<link rel="stylesheet" href="/assets/css/content.css">
<link rel="stylesheet" href="/assets/css/utilities.css">

Drop any layer the project does not use. docs.css is for this site only — never ship it.

Theme init — inline in <head>, before the stylesheet
<script>try{var t=localStorage.getItem('th');
if(t==='light'||t==='dark')document.documentElement.dataset.theme=t;}catch(e){}</script>

This must stay inline and must run before the CSS loads, or the page paints the wrong theme for a frame. It is the one script that cannot be deferred.
